# Personal Git & PR Rules (optional)

Drop these rules into your personal global rules file (e.g.,
`~/.config/opencode/AGENTS.md`) if you want every project you work on to use
this commit and PR style. The core skills do not enforce any format.

- Commit messages and PR titles use `<label>(<optional-scope>): <description>`.
- Strictly all lowercase, imperative present tense, no trailing period.
- Allowed labels: `feat`, `fix`, `refactor`, `perf`, `test`, `docs`, `chore`,
  `style`.
- PR body sections: `## summary`, `## verification`, `## risks`.
